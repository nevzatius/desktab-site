1. Summary

  • Desktab does not require an account, does not show ads, and contains no analytics, telemetry or crash-reporting code.
  • Desktab does not send your files, file names, folder paths or settings to the developer. The Microsoft Store edition uses Windows Microsoft Store APIs for license checks, which may involve communication with Microsoft. Sections 5 and 7 explain this and actions involving other software.
  • Your settings and layout are stored only on your PC, in the application’s own data folder.
  • Desktab sends no workspace data to the developer. If you contact support, the developer receives what you choose to send, by email or in a public GitHub issue. Microsoft may also provide aggregated reports as described in section 7.
  • Microsoft (Windows and the Microsoft Store) and GitHub (this website and public support issues) process some data as separate services. They are described below and are not part of the application itself.

These statements about the application are based on a review of the application’s source code for the version prepared for the first Microsoft Store release. This is a source-code review; it has not been confirmed by monitoring network traffic. If a later version changes these statements, this policy will be updated before that version is released.

2. Who this policy covers

This policy covers (a) the Desktab application for Windows and (b) this website at nevzatius.github.io/desktab-site. The publisher of Desktab is nevzatius, an individual developer. Desktab is currently preparing for its first Microsoft Store release and is not yet publicly available.

3. What the app accesses

The application is a desktop program that runs with your normal user permissions. Its local file and Windows features access the following:

  • Folders you choose. It lists the items in the folders you open as workspaces, using their names and basic attributes (for example, whether an item is a file or a folder), and watches those folders so changes made elsewhere appear automatically. Apart from copying files when you ask it to, the application does not read or index the contents of your files.
  • Icons and previews. Icons and thumbnails are produced by Windows. Windows itself may read parts of a file to create a thumbnail; that processing is done by the operating system, not by Desktab.
  • File operations you request. Open (with the default Windows application for that file type), rename, create a folder, copy, move, and send to the Recycle Bin. The application is designed not to overwrite existing files, and it does not permanently delete files: deleted items go to the Recycle Bin.
  • Clipboard. When you use copy, cut or paste on files, the application writes or reads the file list on the Windows clipboard. Clipboard contents are not stored.
  • Drag and drop. Files you drag between Windows Explorer and Desktab are handled as normal Windows drag-and-drop operations.
  • Desktop items (optional feature). If you use the feature that gathers items from your Windows Desktop into a workspace, the application reads the names, types, sizes and dates of the items on your Desktop to prepare a plan, and moves items only after you confirm. A local record is kept so the move can be undone (see section 4).
  • Background file. If you choose an image, GIF or video as a background, the application reads that file to display it. It is not copied; only its path is remembered.
  • Windows display preferences. The application reads whether Windows is set to light or dark mode, and may use your Windows display language to pre-select the interface language.
  • Keyboard shortcut. The application registers one global shortcut (Ctrl+Shift+Space) with Windows so it can show or hide its own window. It does not record keystrokes.
  • Store license status. The Microsoft Store edition checks the app and Pro add-on license status at startup and when you use Restore, as described in section 7.

4. What is stored on your PC

The application keeps a small settings file and, if you use the Desktop-gathering feature, journal files. They are stored only on your PC, in the application’s own data folder. For the Microsoft Store version this is %LOCALAPPDATA%\Packages\<package family name>\LocalState.

Settings file

  • The paths and names of your workspace folders, and their order and tab settings.
  • Window size and position.
  • For each folder, the position of each item on the workspace (file name and X/Y coordinates).
  • Appearance and language preferences, including the path of a background file if you choose one.
  • For the “Frequent” view: the names, open counts and last-opened times of items you opened from within Desktab.

The application also keeps a backup copy of the settings file so a damaged file can be recovered.

Desktop-gathering journals

If you gather Desktop items, each operation is recorded in a small local file listing the original path, new path, type, size and timestamps of the items moved, so the move can be undone.

Not stored

The application does not store file contents, clipboard contents or log files. If the application hits an unexpected error, it shows a message on your screen; nothing is written to a log or sent anywhere.

File and folder names can be personal. Take care before sharing the settings file or journals with anyone.

5. What the app transmits

Desktab has no account system or server of its own and does not send your workspace files, file names, folder paths or settings to the developer. The Microsoft Store edition calls Windows Microsoft Store APIs to check licenses; these calls may involve communication with Microsoft. When Pro purchasing is enabled, product information and purchase requests also use Microsoft Store (section 7). Some actions you take involve other software, and that software’s behavior is outside Desktab’s control:

  • When you open a file, Windows starts that file type’s default application. That application’s privacy practices apply (for example, a web shortcut opens a browser).
  • If you open a folder that is on a network location or is synchronized by a cloud service (for example, a OneDrive-managed folder), Windows or the sync provider performs the network access, not Desktab.

6. Telemetry and analytics

The application contains no telemetry, usage analytics, advertising, or crash-reporting component. The application cannot report how many people use it, which features they use, or what is in their folders.

7. Microsoft Store and Windows

Desktab is distributed through the Microsoft Store and runs on Windows. Microsoft processes data in connection with those services under its own privacy statement and your Windows settings, for example:

  • Downloading, installing and updating the app, and recording that you have it.
  • Diagnostic and usage data collected by Windows and the Store, depending on your Windows privacy settings.
  • Aggregated reports that Microsoft makes available to the developer through its developer dashboard, such as acquisitions, usage and health summaries. These reports come from Microsoft, not from the application.

The Microsoft Store edition of Desktab uses Windows Microsoft Store APIs to check the app and Pro add-on license status. Cached license information may be used offline when available. Pro is planned as a one-time in-app purchase. When Pro purchasing is enabled, product information and purchase requests are handled through Microsoft Store. Microsoft processes payment and Store licensing data under its own terms; the Desktab developer does not receive your payment card details. In the initial Free release, Pro purchasing is disabled and the app does not offer a purchase action. License checks are not used to send your workspace files or folder contents to the developer.

Microsoft’s privacy statement is available at privacy.microsoft.com.

8. Third-party services

The application contains no advertising, analytics or third-party tracking SDK. The Microsoft Store edition uses the Windows SDK and Microsoft Store APIs for licensing and, when enabled, purchasing, as described in section 7. The third parties involved in connection with Desktab are:

  • Microsoft — Windows and the Microsoft Store, as described in section 7.
  • GitHub — hosting for this website and for the public support issue tracker, as described in sections 9 and 10.
  • Email providers — the services that deliver your email to the developer, if you write to celiknevzatcan7@gmail.com, as described in section 10.

9. This website

This website is a set of static pages hosted on GitHub Pages. The pages themselves do not use cookies, analytics, tracking scripts, advertising, embedded third-party content, or external fonts, and they do not ask you for personal information. The developer has not enabled any visitor analytics for this website.

As the hosting provider, GitHub may process technical data about your visit, such as your IP address and request details, under the GitHub General Privacy Statement.

10. Support inquiries

By email. You can write to celiknevzatcan7@gmail.com. The developer receives your email address and whatever you write, and uses them only to answer your message. The message passes through your email provider and the developer’s email provider, which process it under their own terms. The developer may keep the correspondence for as long as needed to handle your request and, where applicable, to meet legal obligations.

By GitHub Issues. Support and bug reports can also be posted in the public repository linked from the Support page. Anything you post in an issue is public, is visible to anyone, and is processed by GitHub under its terms and privacy statement.

Please do not include passwords, private files, file names or paths you consider private, or other personal information in a public issue, and avoid sending them by email as well. The application does not attach logs or diagnostic data to reports, and the developer does not ask for your settings file.

11. Your choices, access and deletion

  • Your files. Workspace folders are ordinary folders on your PC. Desktab does not delete them or move them anywhere you did not ask it to. They are not part of the application’s data.
  • Local app data. The settings file and journals described in section 4 are ordinary files in the folder shown there. You can delete them yourself at any time (close Desktab first); Desktab then starts with default settings. What happens to that folder when you uninstall the app is decided by Windows and may depend on your Windows version and settings, so this policy does not promise that uninstalling removes it.
  • Data the developer holds. The application sends the developer no personal data. The developer holds personal data only if you choose to send it, for example your email address and message when you write to the address in section 13. Content you post in a public GitHub issue is held by GitHub.
  • Your rights. Depending on where you live, data-protection law may give you rights over personal data the developer holds about you, such as asking for access, correction or deletion. To make a request, write to the address in section 13; the developer may need to confirm that the request comes from the email address concerned. The developer will respond within the time required by applicable law and will delete the data you ask to have deleted unless the law requires or permits it to be kept, for example to meet a legal obligation or to establish, exercise or defend legal claims. If the developer cannot fully comply, it will tell you which part and why. You may also have the right to complain to your local data-protection authority.
  • Microsoft and GitHub. Data held by Microsoft or GitHub is governed by their own policies and tools. You can edit or delete your own posts in a public GitHub issue and may ask the developer to remove an issue, but copies in forks, caches or archives are outside the developer’s control.

12. Children

Desktab does not send personal data from its workspace features to the developer, including for children, and does not include social features, advertising or communication between users. Microsoft Store and Windows data processing is described in section 7.
