Support

Help, bug reports and feedback for Desktab.

Microsoft Store availability

Desktab is preparing for its first public Microsoft Store release. It is not available to download yet. This page will be updated with the Store link once the release is confirmed.

Where to get help

Support, bug reports and feedback are handled through GitHub Issues in the public Desktab website repository:

github.com/nevzatius/desktab-site/issues

You need a free GitHub account to open an issue. Support is provided on a best-effort basis; no response time is guaranteed. No support email address is published at this time.

Issues are public. Anyone can read what you post. Never include passwords, private files, personal information, or file names and folder paths you consider private. If a screenshot shows personal file names, crop or edit it first.

Basic troubleshooting

  • Something looks out of date. Press F5 to refresh the current workspace, or close and reopen Desktab.
  • A file is not shown. Desktab does not list items that Windows marks as hidden or system files.
  • A file will not open. Desktab opens files with the default Windows application for that file type. Check that Windows has an app set for it.
  • I deleted something by mistake. Desktab sends deleted items to the Windows Recycle Bin. Open the Recycle Bin and restore them from there.
  • The Ctrl+Shift+Space shortcut does nothing. Another program may already be using that shortcut. Desktab reports this in its status bar.
  • A video or animated background does not display. The file must be on a local drive (network paths and web addresses are not supported), and video playback depends on the codecs available in Windows. MP4 (H.264) is the safest choice. If the file cannot be played, Desktab falls back to a default background.

How to report a bug

  1. Search the existing issues to see whether it has already been reported.
  2. Open a new issue and choose the bug report form.
  3. Include: your Desktab version, your Windows version, what you did, what you expected, and what happened instead.
  4. Add a screenshot only if it contains nothing private.

Feedback and ideas

Suggestions are welcome. Open an issue in the same repository and describe what you are trying to do and what would help. Please keep one idea per issue.

Supported Windows versions

  • Windows 10, version 2004 (build 19041) or later, and Windows 11.
  • 64-bit (x64) only. ARM64 and 32-bit versions of Windows are not supported.
  • No separate .NET installation is required.

Pre-release testing so far has been done on Windows 10 version 22H2. Testing on Windows 11 is still in progress.

Where to find your app version

Open Windows Settings → Apps → Installed apps (on Windows 10: Apps & features), select Desktab, and open Advanced options. The version number is listed there. Please include it when you report a problem.
